# Data and resource catalog

Every dataset, document, image, piece of code and tool that Astro Romana uses, with a public link, what it is used
for, and its credit or license. This is the list behind the NASA Space Apps Challenge 2026 submission fields
"NASA Data" and "Space Agency Partner & Other Data".

- **Details live next to the data.** Each dataset, part and minigame has its own README with versions, values and
  caveats; this file is the index. Section 8 points to the full citation lists.
- **Links checked:** 2026-11-15.
- **Our own work:** the game code, the 3D models (`assets/models/`, generated by `tools/modeling/`), the soundscape
  (`assets/audio/`, generated by `tools/audio/`) and the prototype mockups in [prototypes/](prototypes/) are made by
  the team. The game shows no third-party image except the HiRISE photos and terrain textures listed in section 1.
