# Self-hosted game fonts

The game bundles the Latin WOFF2 subset of the exact Google Fonts styles it used previously. The files came from the [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2), queried with a Chrome user agent on 2026-11-28. Keep the license files with the fonts when distributing the game.

| `barlow-500.woff2` | https://fonts.gstatic.com/s/barlow/v13/7cHqv4kjgoGqM7E3_-gs51os.woff2 |
| `barlow-600.woff2` | https://fonts.gstatic.com/s/barlow/v13/7cHqv4kjgoGqM7E30-8s51os.woff2 |
